Presentation / MBR formatting preferences (modeled on the "Choice" team's MBR deck).

- Standardized verdicts: 🟢 **On-track** / 🟡 **At risk** / 🔴 **Off-track** (Green→On-track, Yellow→At risk, Red→Off-track). Pale yellow status = on-track, not red.
- **Trend as Q4/Q1/Q2 columns, NOT arrows.** Use `–` where no target exists.
- Layout: table (platforms + global + status) on the **LEFT**; Highlights/Lowlights/Crux on the **RIGHT**. Keep numbers in the table, analysis in text — don't mix. Merge scorecard + "Q-story" into one slide and highlight the leading/lagging platform in the table (don't repeat it in Highlights/Lowlights). Crux = plain-language bullets.
- **Avoid "faffy" words** (e.g. "the accelerating miss", "structural OKR gap", "depth mix shifting deeper").
- Build path: HTML deck → editable PPTX (`slides-from-data` skill; `html2pptx.cjs`). Example: Seamless MBR `/Users/harnoor.chahal/ai/seamless-mbr/`. Choice reference deck `1C7E_gEy_gGqLNuEBkAy0HeoYZNRPbF6CTzHvRe3hh6U`. Related: [[feedback_working_style]].
