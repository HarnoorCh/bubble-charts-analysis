ASSISTANT: For building nice presentations, here are the skills you'd reach for: ## Primary: `slides-from-data` This is the main presentation-builder. It generates slide decks from BigQuery data with: - An **HTML preview** (to review before exporting) - An **editable PPTX export** - The **Delivery Hero Employer Branding template** as the default look (swappable for a custom design) Use it for: data reports as slides, executive dashboards, metric overview decks, turning SQL/query results into a presentation. ## Supporting: `dataviz` Read this **before** any chart goes into the deck. It gives you a consistent, accessible color system and chart specs (stat tiles, KPI rows, sparklines, heatmaps, legends/axes) so all visuals read as one system in light/dark. ## Adjacent helpers - **`google-workspace`** — if you want the deck (or source data) in **Google Slides/Sheets/Docs** instead of PPTX. - **`coredata-analytics`** / **`data-analyst`** — to pull the underlying numbers (orders, GMV, revenue, etc.) that feed `slides-from-data`. --- **Typical flow:** pull data (`coredata-analytics`) → design charts to spec (`dataviz`) → assemble the deck (`slides-from-data`) → preview HTML → export PPTX.
